# CELSIUS Garantías — V8

Actualización sobre la V7 con el logotipo oficial.

## Cambios
- Inicio del cliente sin línea de seguimiento inferior.
- Comunicaciones: novedad principal, actividad reciente, etapas de avisos e historial. Los mensajes son ficticios.
- Dashboard corporativo/maestro: indicadores, prioridades de hoy (abrir expedientes), control de áreas y seis gráficos ilustrativos. Sin bandeja general, sin controles de edición ni gestión de agrupaciones.
- Cuentas y empresas: primero Directorio de cuentas; pestaña Empresas consolidadas. Selección de varias cuentas con casillas y empresa destino en un menú desplegable.
- Se conservan los tres testers y el logo oficial.

## Pruebas
Abrir `index.html` localmente. Usar Vista de prueba para Cliente, Corporativo y Maestra. Las modificaciones de consolidación son temporales y se pierden al recargar. No hay envío real de WhatsApp, autenticación ni persistencia de garantías. No publicar acceso libre a los testers en producción.

## Deploy
Para GitHub Pages o Cloudflare Pages subir los archivos de esta carpeta a la raíz del repositorio. No subir secretos.
